A projekt elkezdéséhez szükséges parancsok: 

npm create vite@latest klonozott_weboldal --template vue 
npm install
ha van benne router: 
npm install vue-router 

projekt elinditása: npm run dev 

Image Gallery fe4ladat megoldása tailwind.css-sel. Funkcionalitásában az oldal jelenleg még nem funkcionál.
